# What's new

The app's ☰ → What's new shows this file, newest first. Each version is a `## ` heading. A blue dot shows on ☰ until a user opens What's new after the top section changes.

Before running **Build apps**, add the version's section at the top, e.g. `## v0.6.4 · Oct 25, 2026`. Build apps uses that section as the release notes, and stops if it's missing.

## v0.6.3 · Oct 23, 2026
